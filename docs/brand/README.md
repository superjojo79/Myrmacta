# Assets de marque Myrmacta

Logo A3b : une fourmi de profil construite avec des formes BPMN, en encre et en corail.
Ce dossier est la référence documentaire. L'application n'est pas câblée depuis ici.

## Couleurs

| Fond | Encre | Corail |
|---|---|---|
| Clair | `#1E2A3A` | `#E4572E` |
| Sombre | `#F3F4F6` | `#FF7A52` |

## Quel fichier pour quel usage

| Fichier | Usage |
|---|---|
| `myrmacta-logo-light.svg`, `myrmacta-logo-light.png` | Logo (fourmi et mot) sur fond clair. Préférer le SVG. |
| `myrmacta-logo-dark.svg`, `myrmacta-logo-dark.png` | Logo sur fond sombre, par exemple la barre latérale. |
| `myrmacta-logo-dark-on-bg.png` | Aperçu du logo sombre déjà posé sur fond encre. Ce n'est pas une source à découper. |
| `myrmacta-icon.svg` | Icône de marque : la fourmi entière, sans le mot. Source vectorielle. |
| `myrmacta-icon.png` | Même icône, 1 200 px. |
| `myrmacta-icon-32.png`, `myrmacta-icon-64.png` | Même icône, 32 et 64 px. |

## Favicon

Le favicon validé le 25/10/2026 est la tête seule, corail, avec deux antennes :

| Fichier | Taille | Usage |
|---|---|---|
| `favicon/favicon-head-16.png` | 16 px | Onglet |
| `favicon/favicon-head-32.png` | 32 px | Onglet |
| `favicon/favicon-head-48.png` | 48 px | Onglet |
| `favicon/favicon-head-180.png` | 180 px | Icône Apple |
| `favicon/favicon-head-512.png` | 512 px | Grande icône |

`favicon/favicon-head-thorax-*.png` (16, 32, 48, 180 et 512 px) est une variante non validée :
tête et thorax. Ne pas l'utiliser comme favicon.

`favicon/preview-favicons.png` est une planche de comparaison, pas un fichier à publier.

Les fichiers à la racine de ce dossier (`favicon.svg`, `favicon.ico`, `favicon-16.png`,
`favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`) recopient ce que sert
`frontend/public/`. Les PNG 16, 32, 180 et 512 px sont les mêmes octets que
`favicon-head-16.png`, `favicon-head-32.png`, `favicon-head-180.png` et
`favicon-head-512.png`.
