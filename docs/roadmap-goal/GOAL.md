# Commande /goal (à coller telle quelle)

```
/goal Implémenter toute la roadmap FlowForge (Vague D) en suivant docs/roadmap-goal/CHARTE.md, qui fait foi (périmètre, ordre, règles de décision). Pour CHAQUE lot de la charte §2, dans l'ordre : dev-lifecycle Phases 1 à 9 sans saut (docs requirements/design/planning/implementation/testing, TDD, point TODO.md, doc utilisateur, CHANGELOG, exposition MCP dans le même lot) PUIS Phase 10 : revue adversariale par un sous-agent indépendant, toute faille Critique/Haute/Moyenne corrigée en TDD avec test de régression (seconde passe si Critique/Haute). Je délègue les décisions ouvertes : tranche-les selon CHARTE §4 (1. cohérence avec les décisions déjà posées, non négociable ; 2. valeur produit maximale pour intégrateurs et utilisateurs low-code, pas le choix le plus rapide) et consigne CHAQUE décision au moment où elle est prise dans docs/roadmap-goal/DECISIONS.md (options, choix, justification, cohérence, réversibilité, ⚠ à revoir) et dans TODO.md. Ne jamais : relâcher l'allowlist BPMN, scriptTask natif, JUEL pour l'expression métier, Redis, licence AGPL, désactiver/ignorer un test. Une décision qui contredit un choix figé = option écartée ; lot impossible sans cela = « Bloqué » motivé dans AVANCEMENT.md, passer au suivant. Commits et push sur la branche de développement à la fin de chaque lot ; aucune PR ni merge. Tiens docs/roadmap-goal/AVANCEMENT.md à jour à chaque phase. TERMINÉ quand : tous les lots de la charte sont Livré, Bloqué (motif) ou Non traité (motif), aucun À faire/En cours ; ET, sur le HEAD final, les sorties fraîches de `./mvnw verify` et de `cd frontend && npm run test:all` sont affichées avec 0 échec ; ET ROADMAP.md, FILE-ATTENTE.md, README.md (Statut) et CHANGELOG.md sont alignés ; ET tu as affiché le tableau AVANCEMENT final et la liste des décisions ⚠ de DECISIONS.md ; ET tout est poussé.
```
